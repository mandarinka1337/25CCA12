# 📥 Как скачивать файлы — подробная инструкция

Репозиторий **публичный** — доступен каждому, даже без аккаунта на GitHub.

Что внутри:

```
25CCA12/
├── !25-ССА-12_Algo/              ← лабораторные (папки по датам пар)
│   ├── 2026-09-10/
│   │   ├── UserCharp/            ← на C#
│   │   ├── UserPac/              ← на Delphi
│   │   └── UserPy/               ← на Python
│   └── 2026-09-12/
│       └── ... (так же)
└── installers/                   ← установщики сред разработки
    ├── vs_setup.exe              (~2 МБ, обычный файл)
    └── Embarcadero.Delphi...     (~424 МБ, через Git LFS)
```

Ниже — четыре способа. Выбери один, какой удобнее.
Способ 1 — самый простой (мышкой). Способ 2 — скачивает только одну нужную дату. Способ 3 — всё целиком. Способ 4 — только установщики.

## СПОСОБ 1. Через сайт, без консоли

1. Открой в браузере: **https://github.com/mandarinka1337/25CCA12**
2. Кликни по папке **`!25-ССА-12_Algo`** — откроется список папок по датам.
3. Кликни по нужной дате, например **`2026-09-12`**.
4. Внутри будут папки `UserCharp`, `UserPac`, `UserPy`. Заходи в нужную (например `UserCharp`), потом в задание (`Ur2`, `Ur5`…).
5. Кликни на файл — откроется страница файла. Нажми кнопку **Download** (кнопка со стрелкой вниз, справа сверху). Файл скачается в папку «Загрузки».

Хочешь скачать весь репозиторий разом мышкой? На главной странице нажми зелёную кнопку **Code ▾** → **Download ZIP**. Скачается архив со всем содержимым (кроме Delphi-установщика — он в LFS, см. Способ 4).

> GitHub не умеет скачивать одну папку кнопкой «скачать папку». Для этого есть Способ 2.

## ПРЕДВАРИТЕЛЬНЫЙ ШАГ. Установить Git

Нужен только для способов 2 и 3.

1. Открой в браузере: **https://git-scm.com/downloads/win**
2. Скачается файл-установщик (например `Git-2.45.0-64-bit.exe`).
3. Запусти его. Во всех окнах жми **Next → Next → Install…**, оставляя значения по умолчанию. Ничего менять не нужно.
4. После установки закрой и заново открой окно **PowerShell** (см. ниже) — иначе команда `git` может не найтись.

### Как открыть PowerShell (окно для команд)

- Нажми `Windows + R`, введи `powershell` и нажми Enter.
- Или нажми `Пуск`, начни печатать «PowerShell» и открой приложение **Windows PowerShell**.

Команды копируются обычным `Ctrl+C` и вставляются `Ctrl+V`.

Проверь, что git установился — введи:

```
git --version
```

Если в ответ появилось что-то вроде `git version 2.45.0.windows.1` — всё готово, можно продолжать.

## СПОСОБ 2. Скачать только одну папку-дату

Скачивается **только** выбранная дата (например `2026-09-12`), остальное не грузится. Ничего больше ставить не нужно.

### Шаг 1. Создай папку, куда сохранять

```
mkdir C:\downloads_cca
```

### Шаг 2. Зайди в неё

```
cd C:\downloads_cca
```

### Шаг 3. Скопируй репозиторий (без содержимого, только каркас)

Вставь одну команду целиком и нажми Enter:

```
git clone --no-checkout --depth 1 --filter=blob:none --sparse https://github.com/mandarinka1337/25CCA12.git
```

Появится папка `25CCA12`. Дождись надписи `done`.

### Шаг 4. Зайди в неё

```
cd C:\downloads_cca\25CCA12
```

### Шаг 5. Укажи, какую дату скачать

Вставь команду (дата `2026-09-12` — пример, можно заменить на любую из списка):

```
git sparse-checkout set "!25-ССА-12_Algo/2026-09-12"
```

Если нужна другая дата — просто замени в команде `2026-09-12` на нужную (список дат видно в репозитории внутри папки `!25-ССА-12_Algo`).

### Шаг 6. Готово

Файлы лежат здесь:

```
C:\downloads_cca\25CCA12\!25-ССА-12_Algo\2026-09-12\
```

Открой проводник, вставь в адресную строку `C:\downloads_cca\25CCA12\` — увидишь папки `UserCharp`, `UserPac`, `UserPy`.

## СПОСОБ 3. Скачать весь репозиторий

Скачиваются **все** папки-даты и всё остальное (кроме Delphi-установщика, он сам по себе, см. Способ 4).

### Шаг 1

```
mkdir C:\downloads_cca
```

### Шаг 2

```
cd C:\downloads_cca
```

### Шаг 3

```
git clone https://github.com/mandarinka1337/25CCA12.git
```

### Шаг 4

```
cd C:\downloads_cca\25CCA12
```

Всё уже скачано. Проверь:

```
dir
```

Ты увидишь папки `!25-ССА-12_Algo`, `installers`, а также файлы `README.md` и т.д.

Если нужны и установщики (`vs_setup.exe` ~2 МБ и Delphi ~424 МБ — они хранятся через Git LFS), выполни:

```
git lfs pull
```

git установит Git LFS-поддержку сам, в первый раз спросит — подтверди установку. После этого в папке `installers/` появятся настоящие файлы.

## СПОСОБ 4. Установщики отдельно

Скачивает только нужный файл, без репозитория.

### Visual Studio (около 2 МБ)

В PowerShell вставь и нажми Enter:

```
curl -L -o vs_setup.exe "https://media.githubusercontent.com/media/mandarinka1337/25CCA12/main/installers/vs_setup.exe"
```

Файл при этом появится в папке, где открыт PowerShell (в начале набери `cd C:\downloads_cca`, чтобы скачать туда).

### Delphi 10.3 Rio Lite (около 424 МБ)

```
curl -L -o delphi-lite.exe "https://media.githubusercontent.com/media/mandarinka1337/25CCA12/main/installers/Embarcadero.Delphi.10.3.0.v26.0.32429.4364.Lite.v15.0.exe"
```

Скачивание займёт время — это нормально, файл большой. Прерывать процесс не нужно.

## ЧАСТЫЕ ВОПРОСЫ И ПРОБЛЕМЫ

**«git» не является внутренней или внешней командой / не найден.**
Git не установлен (или окно открыли до установки). Доделай раздел «Предварительный шаг» выше, затем закрой и открой PowerShell заново.

**Команда вставилась, но идёт ошибка про «не найден путь» / странные символы.**
Убедись, что вставляешь команду целиком, в одну строку. Из-за кириллического имени папки обязательно используй **PowerShell** (не cmd), и не добавляй от себя пробелов или кавычек.

**Хочу другую дату — что заменить?**
В Способе 2 в команде `git sparse-checkout set "!25-ССА-12_Algo/ХХХХ-ММ-ДД"` замени `ХХХХ-ММ-ДД` на нужную дату. Посмотреть список дат можно на сайте, внутри папки `!25-ССА-12_Algo`.

**Скачал ZIP через «Download ZIP» — а Delphi-установщика нет.**
Он хранится через Git LFS и в ZIP не попадает. Скачивай его по Способу 4.

**Tried вариант с svn?**
Если у тебя установлен svn (например, TortoiseSVN), можешь скачать одну дату одной командой:

```
svn export https://github.com/mandarinka1337/25CCA12/trunk/!25-ССА-12_Algo/2026-09-12
```

Но если svn нет — эта команда не нужна, пользуйся Способом 2.

**Что если после обновлений у меня устаревшие файлы?**
Для способа 2 и 3 просто заново выполни шаг 5 (способ 2) или команду `git pull` внутри папки `25CCA12` (способ 3) — придут новые версии.
