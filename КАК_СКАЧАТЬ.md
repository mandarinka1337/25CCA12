# 📥 Как скачивать файлы

Репозиторий **публичный** — доступен каждому без регистрации.

---

## 1. Через сайт (без консоли)

1. Открой https://github.com/mandarinka1337/CCA12-
2. Зайди в нужную папку, напр. `!25-ССА-12_Algo/2026-09-10/UserCharp/Ur2/`
3. Нажми на файл → кнопка **Download** (иконка ↓)

> Целиком папку GitHub одной кнопкой не скачивает.

---

## 2. Скачать только одну папку-дату через консоль

```bash
# Вариант А — svn (коротко)
svn export https://github.com/mandarinka1337/CCA12-/trunk/!25-ССА-12_Algo/2026-09-12

# Вариант Б — git (есть у всех)
git clone --no-checkout --depth 1 --filter=blob:none --sparse https://github.com/mandarinka1337/CCA12-.git
cd CCA12-
git sparse-checkout set "!25-ССА-12_Algo/2026-09-12"
```

---

## 3. Клонировать весь репозиторий

```bash
git clone https://github.com/mandarinka1337/CCA12-.git
cd CCA12-
```

Все папки-даты скачаются целиком. **Установщики** в папке `installers/` лежат в Git LFS, докотай их отдельно и только если нужны:

```bash
git lfs pull
```

---

## 4. Установщики без клонирования

```bash
# Visual Studio (~2 МБ)
curl -L -o vs_setup.exe "https://media.githubusercontent.com/media/mandarinka1337/CCA12-/main/installers/vs_setup.exe"

# Delphi 10.3 Rio Lite (~424 МБ)
curl -L -o delphi-lite.exe "https://media.githubusercontent.com/media/mandarinka1337/CCA12-/main/installers/Embarcadero.Delphi.10.3.0.v26.0.32429.4364.Lite.v15.0.exe"
```
