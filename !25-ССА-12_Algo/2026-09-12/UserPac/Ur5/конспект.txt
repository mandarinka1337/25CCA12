Понятие типа данных и переменной.

Практически любая программа получает на вход какие-либо данные, обрабатывает их и генерирует выходную информацию. Для этого типизированный язык программирования должен знать, с какими данными он имеет дело и какие операции над ними можно производить.

Жизненный цикл программы:
1. Постановка задачи
2. Определение данных и результатов вычислений
3. Словестный алгоритм
4. Написание кода
5. Тестирование и отладка
6. Компиляция - выпуск программы

Тип данных (англ. Data type) - характеристика, определяющая: множество допустимых значений,
 которые могут принимать данные, принадлежащие к этому типу (например, объект типа
 Целое число может принимать только целочисленные значения в определенном диапазоне);

 Организация хранения данных в памяти компьютера.
Данные и код программы хранятся в оперативной памяти компьютера
Количество памяти, требуемой для экземпляров данных (в байтах), и место их хранения
зависит от используемого ими типа
Например целые числа:
тип      кол байт

shortint   1         -128..127
byte       1         0..255
integer    2          -32768..32767
word       2          0..65535
longint    4          -2147483648..2147483647

В Python 4 базовых типа: Логический, числовой: целые и вещественные, символьный
        конструируемые: строка массив список словарь
Использует динамическую типипзацию

C#, pascal - применяют строгую статическую типизацию

При выполнении программы для хранения данных используются два участка оперативной памяти:
стеком (stack)- статический участок - хранится постоянно пока работает программа
кучей (heap) - динамический участок - хранится временно по мере выполнения кода



Набор операций, которые можно осуществлять над данными, принадлежащими к этому типу
(например, объекты типа Целое число умеют складываться, умножаться и т.д.).

Переменная (англ. Variable) - это идентификатор, который указывает на определенную область
памяти, где хранятся произвольные данные - созданный объект (значение переменной).

Статическая типизация — приём, широко используемый в языках программирования, при котором
переменная, параметр подпрограммы, возвращаемое значение функции связывается с типом в
момент объявления и тип не может быть изменён позже (переменная или параметр будут принимать,
а функция — возвращать значения только этого типа).
Примеры статически типизированных языков — Ада, C, С++, C#, D, Java, ML, Паскаль, Solidity,
Go, Fortran. Противоположный приём — динамическая типизация.

Динамическая типизация — приём, используемый в языках программирования и языках спецификации,
при котором переменная связывается с типом в момент присваивания значения,
а не в момент объявления переменной.
